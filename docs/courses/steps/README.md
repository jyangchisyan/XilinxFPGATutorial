## 與原六課的關係

- 原第 01 課：小節 01–04。
- 原第 02 課：小節 05–06。
- 原第 03 課：小節 07–16，以及頂層整合的後續練習。
- 原第 04 課：小節 17–20，其中時脈換算也會反覆使用第 07、08 節。
- 原第 05、06 課的自訂硬體與 DDR2／時序進階內容，保留在原課程，尚未在這份互動紀錄中逐題授課。

檔案以觀念順序安排，不是逐字逐句的聊天轉錄。原始對話中的錯誤答案已轉成釐清觀念的例子；答案可折疊，方便先自己練習。

此目錄只整理教材與已有實驗結果，不會修改目前正在使用的韌體、RTL 或 bitstream。
