# 11：同步重置也要等上升緣

[上一節](10-clock-edges.md) · [小單元目錄](README.md) · [下一節](12-nonblocking-assignment.md)

## 這節只學一件事

判斷重置生效的時間，要一起看 `always` 的觸發條件。

```verilog
always @(posedge clk) begin
    if (rst) begin
        count <= 0;
        led   <= 0;
    end else begin
        // 正常的計數規則
    end
end
```

這是高有效、同步重置：上升緣看到 `rst = 1`，才把狀態歸零。

| rst 的變化 | 下一個上升緣看到什麼 | 結果 |
| --- | --- | --- |
| 在兩個上升緣之間變成 1，維持到下一緣 | 1 | 到下一個上升緣才歸零 |
| 變成 1，但在下一個上升緣前恢復 0 | 0 | 這段短脈衝不會觸發同步重置 |

這裡討論理想數位模擬與同步邏輯。實體非同步輸入若接近取樣邊緣變化，還需要考慮同步與實際時序要求。

## 為什麼容易答成「立即歸零」？

因為看到 `if (rst)` 就直接判斷條件，忽略了程序尚未被時脈事件觸發。先看「何時執行」，再看「執行哪個分支」。

## 練習

目前 count 為 7。rst 在下降緣後變成 1，並維持兩個上升緣。在第一個上升緣前、第一個上升緣後，count 分別是多少？

<details>
<summary>查看答案</summary>

第一個上升緣前仍為 7；第一個上升緣後為 0。第二個上升緣若 rst 仍為 1，繼續保持 0。

</details>

## 過關標準

能用時間順序解釋重置，並知道短於取樣間隔的脈衝可能被同步重置漏掉。
