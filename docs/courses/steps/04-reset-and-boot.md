# 04：準備完成後，CPU 才開始執行

[上一節](03-bram-and-ddr.md) · [小單元目錄](README.md) · [下一節](05-delay-and-duty.md)

## 這節只學一件事

理解目前系統為什麼需要安排開機順序。

本專案的韌體一開始就會測試 DDR2。如果 DDR2 尚未準備好就讀寫，交易可能等待，測試結果也無法可靠判斷記憶體功能。

因此硬體安排以下順序：

```text
時脈穩定
    ↓
MIG 初始化與校準 DDR2
    ↓
Reset Controller 解除 CPU 重置
    ↓
CPU 從 BRAM 的啟動位址取指令
    ↓
啟動程式初始化 → main() → DDR2 測試
    ↓
測試成功，LED 規律閃爍
```

CPU 處於重置時，維持在重置狀態，尚未正常執行應用程式。解除重置後，從指定的啟動位址開始取指令。

FPGA 設定完成、CPU 開始執行、記憶體測試通過，是三個不同的觀察點。

## 練習

把「程式放在哪裡、何時開始執行、成功後看到什麼」串成一句話。

## 過關標準

能說明 CPU 為什麼等待 ready，且不把下載成功直接視為全部應用功能通過。
