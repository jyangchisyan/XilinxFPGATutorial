# 02：位址選擇裝置，資料決定內容

## 這節只學一件事

區分一次寫入交易中的「位址」與「資料」。

原韌體中有這個定義：

```c
#define GPIO_DATA (*(volatile uint32_t *)0x40000000u)
```

執行 `GPIO_DATA = 1` 時：

| 資訊 | 值 | 意義 |
| --- | --- | --- |
| 位址 | `0x40000000` | 這個系統將它配置給 AXI GPIO |
| 資料 | `1` | GPIO 的 bit 0 設為 1，LED 亮 |

執行 `GPIO_DATA = 0` 時，位址不變，資料改為 0，LED 熄滅。

同樣寫入數值 1，若目的位址是 `0x80000000`，系統會將交易導向 MIG，寫入 DDR2。裝置選擇依據是硬體的位址配置；變數名稱是方便閱讀 C 程式的表示法。

`volatile` 要求編譯器保留這個實際存取。硬體端仍需要正確的位址解碼與連線。

## 練習

`GPIO_DATA = 0` 的位址、資料與 LED 結果分別是什麼？

<details>
<summary>查看答案</summary>

位址 `0x40000000`，資料 0，LED[0] 暗。位址仍選擇同一個 GPIO 暫存器。

</details>
