# 12：非阻塞賦值讀取更新前的值

[上一節](11-synchronous-reset.md) · [小單元目錄](README.md) · [下一節](13-compare-old-state.md)

## 這節只學一件事

在本課這種時脈程序中，`<=` 的右側讀取當次更新前的狀態，再安排暫存器更新。

```verilog
always @(posedge clk) begin
    a <= b;
    b <= a;
end
```

如果原本 `a = 1`、`b = 0`：

| 敘述 | 讀取的值 | 安排的更新 |
| --- | --- | --- |
| `a <= b` | 舊 b = 0 | a 更新為 0 |
| `b <= a` | 舊 a = 1 | b 更新為 1 |

結果是交換：`a = 0`、`b = 1`。第二行仍使用舊 a，不會因為寫在後面就改讀新 a。

## 再看一個例子

```verilog
count <= count + 1;
saved <= count;
```

原本 count 為 5，更新後 count 為 6，saved 為 5。saved 保存的是本次更新前的 count。

這個規則很適合描述同一時脈邊緣觸發的多個暫存器。先不要在同一暫存器上混用不同程序或多次賦值，避免加入額外的優先序問題。

## 練習

原本 `x = 3`、`y = 8`，執行 `x <= y; y <= x + 1;` 後各是多少？

<details>
<summary>查看答案</summary>

x 為 8，y 為 4。兩個右側都使用舊狀態，所以 y 使用舊 x = 3 來加一。

</details>

## 過關標準

能先列出所有舊值，再計算各右側結果，最後一起填入新值。
